# Catppuccin Mocha for Serein

[Catppuccin Mocha](https://catppuccin.com/) with a **Blue accent** for the native
[Serein Discord client](https://github.com/ViceVerse-cz/Serein).

## Download and install

1. [Download the theme](https://github.com/LyKhoris/SereinCatppuccin/releases/latest/download/catppuccin-mocha-blue.serein-extension).
2. In Serein, open **Settings → Themes**, import the file, and choose **Use theme**
   for **Catppuccin**.
3. Use **Dark** appearance with **Transparency & blur** off for the intended colors.
   Restart Serein if you change that effects switch.

No plugin or build step needed. Both appearance modes use Mocha.
Reset with **Ctrl+Shift+F12**.

All theme colors come from the official Mocha palette. Serein generates some
interaction shades and uses hard-coded white on certain controls.
